## 슬라이드마다 자리를 더 추가하고 싶으면

각 슬라이드 맨 아래에 점선 테두리 **"+ 스크린샷 / 영상 추가"** 버튼이 있습니다(편집 모드에서만 보임).
누르면 그 슬라이드에 빈 자리가 새로 생기고 바로 파일 선택창이 열립니다 — 몇 개든 계속 추가할 수 있습니다.
이렇게 추가한 자리는 파일명 규칙과 무관하게 그 자리에서 바로 업로드한 파일만 사용합니다.

## 그냥 편집 모드로 넣어도 됩니다

파일명을 맞추기 귀찮으면, 웹 PPT 우측 상단 **"✏️ 편집 모드"** 버튼을 누르고
각 페이지의 빈 이미지 자리를 클릭해서 바로 업로드해도 됩니다. 업로드한 파일은
페이지에 base64로 박히지 않고 **이 `assets/` 폴더에 링크로 연결**됩니다
(로컬 서버+크롬/엣지면 자동 복사, 아니면 파일이 다운로드되니 이 폴더로 옮기세요).
**"⬇ 수정본 다운로드"** 로 저장하면 `assets/` 링크만 남아 HTML이 가볍게 유지됩니다.
개발자용 편집/링크 규칙은 상위 폴더의 [`../README.md`](../README.md) 참고.
