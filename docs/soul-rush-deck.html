03 GAME

로그라이크 규칙 & 핵심 루프

로그라이크 규칙
  • 다음 보스로 이동, 보스 레이드 최대 8판(추후 변경 가능)

핵심 게임 루프
보스 처치→ 스킬 보상 선택/강화→ 다음 층 이동→ 난이도 상승→ 클리어 · 팀 랭킹

06 ARCHITECTURE

실제 서버 API & 통신 흐름 soulrush_api (PHP)

인증 · 세션
  • register.php · login.php — 가입 / 로그인
  • check_session.php — 15초 하트비트, 중복 로그인 차단
  • check_admin.php — 디버그 권한 검증
스킬 (밸런스 DB)
  • get_abilities.php — 스킬 수치 카탈로그 조회
  • update_skills.php — 해금 비트마스크 저장
  • upload_ability.php — (에디터) 스킬 업로드
랭킹 · 크래시
  • submit_ranking.php / get_rankings.php — 팀 기록
  • crash_report.php — 크래시 자동 수집
관리용 웹 & DB
  • 웹 뷰어: admin_hub · crash_viewer · ranking_viewer · log_viewer
  • 테이블: users · abilities(7) · team_rankings · crash_reports
접속부터 클리어까지 — 서버 통신 흐름
1서버 자동 탐지같은 랜이면 LAN IP, 아니면 공인 IP (포트 8080)
2로그인login.php → 세션 토큰 + 해금 비트마스크 수신
3세션 유지15초마다 check_session, 중복 접속 차단
4스킬 최신화get_abilities로 서버 밸런스 반영
5클리어submit_ranking으로 팀 기록 등록

09 PROGRESS — 임현빈

스킬 시스템 — 타입 & 데이터 구조

3가지 타입 (ScriptableObject 모듈)
  • Active — 슬롯 장착·직접 사용. 쿨타임·스태미나·HitEvents·레벨별 데미지 배율
  • Passive — 획득/레벨업 시 스탯 상승(체력·스태미나·방어·공격력 %)
  • Utility — 회복·기본공격 해금 등 기능성
하이브리드 데이터
  • 연출값(애니메이션·VFX·사운드·히트박스) = Unity 로컬 에셋
  • 밸런스 수치(쿨타임·데미지·레벨값) = 서버 DB — 로그인 시 최신화, Bake로 에셋 갱신
  • AbilityManager가 전체 카탈로그 관리
