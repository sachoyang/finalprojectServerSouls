전투 시스템 — Down & Revive

Down 상태 전환
  • HP가 0이 되면 즉시 게임오버가 아니라 Down 상태로 전환
  • Down 상태에서는 느린 크롤링 이동만 허용, 전투 입력 제한
  • 사망 플레이어도 전투 흐름 안에서 구조 대상이 되도록 관리

보스 시스템 — 상태머신 (NetworkBossCore)

보스 상태 흐름 — State Machine
Sleep 대기 →근접 감지 WakeUp 포효 → Idle ↔ Walk 추적 ⇄쿨타임 ExecutingPattern SO 패턴
PhaseTransition HP 50%↓ 광폭화 → 2페이즈 패턴 • Groggy 그로기 딜타임 • Die HP 0
WakeUp — 플레이어가 wakeUpRange 진입 시 포효 후 전투 개시
PhaseTransition — HP 50% 이하 자동 진입, CurrentPhase=2 → phase2 패턴으로 교체(광폭화)
Groggy — 누적 그로기 ≥ maxGroggy 시 정지, 받는 데미지 ×1.5 딜타임
ExecutingPattern — BossPatternSelector가 사거리 필터 + 가중치로 패턴 추첨
